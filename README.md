# محصّل الغاز

التطبيق يعمل على الهاتف، ويعمل بدون إنترنت
لتحصيل فواتير الغاز من المشتركين. 
تجريبي على 
عينة أولية من المحصلين، وقابل للتوسعة

## كيف يعمل


1 **المستخدم** يفتح رابط التطبيق، ويدخل مرة واحدة يوميا برقم أدائه وكلمة سره، فينزّل الملفات المحدث على هاتفه. بعدها يعمل بدون إنترنت طوال اليوم
المستخدم يتصفح
(قطاع ← بلوك ← عمارة ← شقة)
 ويسدد، ويتراجع حتى نهاية اليوم
ويبحث باسم العميل او رقم المشترك
ويسجل سداداً مقدماً، 
ويطبع بيان مستحقات

ويسجل قراءة عداد
3. المستخدم يرسل **أرشيفه** للأدمن عبر واتساب أو غيره
4. الملفات تعتبر نهائية غير قابلة للتعديل فى بداية اليوم الجديد
